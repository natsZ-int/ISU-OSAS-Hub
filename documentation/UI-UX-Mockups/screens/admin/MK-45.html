Target records are not linked: the record may have moved or been removed, and the audit entry must remain readable regardless.

Design intent

Show one audit entry in full, including the request context captured with it.

What this screen establishes

  1. All captured context is shown: actor, action, module, record type and id, description, IP address, user agent and timestamp.
  2. The description is displayed as stored, without interpretation.
  3. The entry cannot be modified or deleted; there are no actions on this screen.
  4. Related entries for the same record can be listed to reconstruct a sequence.

Structural source: WF-A-23 in the wireframe set. The mockup restates the same information architecture in the institutional palette, so a change to one is a change to both.
