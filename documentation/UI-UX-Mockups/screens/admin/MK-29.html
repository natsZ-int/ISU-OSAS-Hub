Booking rules

Effect on a booking

A student looking at today at 07:00 sees no slot before 11:00, because the minimum booking notice is 240 minutes. A student cannot request a date more than 30 days ahead. A confirmed appointment can be cancelled by the student until 24 hours before it starts; afterwards the Guidance Office must intervene. Slots are only generated inside 08:00 – 17:00 and inside a published availability block.
!
Changes are immediateSettings apply to the next slot request. Appointments already booked are not rescheduled automatically.

Design intent

Set the office hours, default duration, minimum booking notice, cancellation notice and booking horizon used by the slot generator.

What this screen establishes

  1. Office start must precede office end; both are time values on a 24-hour clock.
  2. Default duration applies when an appointment type does not specify one.
  3. Minimum booking notice prevents a student booking a slot a few minutes ahead.
  4. Cancellation notice is the cut-off after which the student must contact the office.
