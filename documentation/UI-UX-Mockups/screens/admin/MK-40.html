Export uses the same filters and produces identical totals. A report that disagrees with the screen is a defect, not a rounding difference.

Design intent

Present volume and outcome metrics across scholarships, guidance and services for a chosen period, with an export of the same filtered dataset.

What this screen establishes

  1. The period filter is the primary control and applies to every figure on the screen.
  2. Summary cards are counts, not rates, so they can be reconciled with the queues.
  3. Tabs switch between the three analytical views without losing the period filter.
  4. Export produces exactly the dataset on screen for the active period and tab.

Structural source: WF-A-24 in the wireframe set. The mockup restates the same information architecture in the institutional palette, so a change to one is a change to both.
