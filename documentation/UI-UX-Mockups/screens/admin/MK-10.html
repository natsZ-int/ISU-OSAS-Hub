There is exactly one administrator tier. No super administrator, adviser or OSAS-staff role exists in the delivered system.

Design intent

List every account with its role and active state so the administrator can suspend, restore or edit access.

What this screen establishes

  1. Role filter is the primary control, because role determines which screens a user can reach.
  2. Active state is a first-class column: an inactive account is refused at login even with correct credentials.
  3. Only three roles exist — student, counselor and administrator. There is no super administrator tier.
  4. Deactivation is a toggle, not a delete, so historical records keep a valid owner.

Structural source: WF-A-02 in the wireframe set. The mockup restates the same information architecture in the institutional palette, so a change to one is a change to both.
