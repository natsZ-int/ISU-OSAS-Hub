Resetting clears the stored hash. The student sets a new passcode on their next visit.

Design intent

Show one student's complete record, including enrollment outcome, passcode state and the eligibility inputs the system actually uses.

What this screen establishes

  1. Contact and household details are shown only to administrators; a counselor never reaches this screen.
  2. Passcode state is shown as set or not set; the hash is never displayed.
  3. Resetting a forgotten passcode clears the hash and requires the student to set a new one; the action is audited.
  4. The enrollment panel links to the verification record for the current term.

Structural source: WF-A-06 in the wireframe set. The mockup restates the same information architecture in the institutional palette, so a change to one is a change to both.
