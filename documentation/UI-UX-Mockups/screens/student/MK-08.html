Removing protection deletes the stored hash. This cannot be undone.

Forgotten your passcode?

Only an OSAS administrator can reset a forgotten passcode. Visit the OSAS office with your student ID. The reset is recorded in the audit log.

Design intent

Let the student set, change or remove a passcode that locks profile fields for the current session.

What this screen establishes

  1. Three states are shown: no passcode set, passcode set and unlocked, passcode set and locked.
  2. Current passcode is required to change or remove an existing passcode.
  3. The stored value is a one-way hash; the plaintext is never displayed or returned.
  4. Unlock attempts are throttled and the remaining attempts are shown after a failure.

Structural source: WF-S-04 in the wireframe set. The mockup restates the same information architecture in the institutional palette, so a change to one is a change to both.
