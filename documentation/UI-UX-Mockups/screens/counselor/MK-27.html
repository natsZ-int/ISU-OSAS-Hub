Blocking rule

A new block may not overlap an existing block on the same day. An overlap is rejected and the existing block is left untouched. Appointments already booked inside a block keep their slot even if the block is later shortened.

Design intent

Publish the recurring weekly blocks from which bookable appointment slots are generated, and mark a day unavailable without deleting its history.

What this screen establishes

  1. One row per day of week (1 = Monday … 7 = Sunday), with a start time, an end time and an available flag.
  2. Saving a block that overlaps another block for the same counselor is rejected with a field-level error.
  3. End time must be later than start time; the pair is validated server-side too.
  4. The preview column shows the resulting bookable slots so the effect of a change is visible before saving.

Structural source: WF-C-02 in the wireframe set. The mockup restates the same information architecture in the institutional palette, so a change to one is a change to both.
