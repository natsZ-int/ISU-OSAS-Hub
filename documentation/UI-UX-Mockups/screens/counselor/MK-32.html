Completion is irreversibleOnce an appointment is marked completed it cannot return to confirmed, because the state machine has no reverse transition.

Design intent

Review one appointment request with the student's stated reason, then confirm, reject with a required reason, or complete a confirmed session.

What this screen establishes

  1. Only transitions permitted by the state machine are rendered as actions.
  2. Reject requires a written reason; the reason is shown to the student verbatim.
  3. Confirm re-checks the slot for conflict before committing, so a stale page cannot double-book.
  4. Complete is available only from confirmed, and stamps the completion in history.

Structural source: WF-C-04 in the wireframe set. The mockup restates the same information architecture in the institutional palette, so a change to one is a change to both.
