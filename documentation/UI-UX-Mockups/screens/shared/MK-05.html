You don't have access to this page

Your account does not carry the role this page requires. If you believe this is a mistake, contact the OSAS office and quote your student number.

404 variant — record not found The same layout is used when a record does not exist or is not open to students:
404 · Page not found
This scholarship is not open, or the address is incorrect.

Design intent

Refuse an unauthorised request without disclosing whether the record exists, and explain the refusal in plain language.

What this screen establishes

  1. 403 is returned when an authenticated user requests another role's route.
  2. 404 is returned for a missing record and for a scholarship that is not open.
  3. No record data is rendered on either page — no titles, identifiers or counts.
  4. Recovery actions are limited to safe destinations for the current role.

Structural source: WF-G-04 in the wireframe set. The mockup restates the same information architecture in the institutional palette, so a change to one is a change to both.
