Role variantsThe counselor shell replaces Management with Guidance and OSAS sections; the administrator shell adds Management, Insights and System sections. The frame dimensions never change between roles.

Design intent

Define the persistent frame shared by every authenticated page: a 264 px sidebar, a 60 px top bar, and a single main content region.

What this screen establishes

  1. Sidebar width is fixed at 264 px on desktop and holds role-appropriate links only.
  2. Section labels group links; the active link carries a left rule and a filled background.
  3. The notification count appears twice: on the sidebar link and on the top-bar bell.
  4. Top bar carries the menu toggle (small screens), quick search, bell, user chip and logout.

Structural source: WF-G-06 in the wireframe set. The mockup restates the same information architecture in the institutional palette, so a change to one is a change to both.
